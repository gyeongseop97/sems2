# 담당자 업무 흐름 개선 (2026-09-23)

- 담당자 첫 화면에 요청별 할 일, 수정 요청, 마감 임박, 제출 현황을 통합했습니다.
- 요청 항목에서 법인·사업장·기간·Scope 또는 ESG 지표가 채워진 입력창으로 이동합니다.
- 반려 사유를 카드와 입력창에 표시하고 수정 후 재제출할 수 있습니다.
- 온실가스 단건·일괄 입력 및 ESG 입력에서 임시저장과 제출을 구분합니다.
- 제출 전 검증된 값과 단위·세부값·이상치 경고를 확인하며, 수정 화면으로 돌아갈 수 있습니다.
- 필수 입력 오류 목록에서 해당 입력란으로 이동합니다.
- 선택지가 하나인 항목은 고정값으로 표시합니다.
- 담당자 메뉴는 내 할 일·데이터 입력·증빙자료를 우선 표시하고 전체 메뉴를 펼칠 수 있습니다.
- 관리자 법인별 현황표의 건수를 누르면 해당 상태와 법인으로 자료를 필터링합니다.
- 저장 상태를 서버 응답에 따라 표시하고 실패 시 다시 저장할 수 있습니다.
- 저장된 상태 코드는 유지하며 화면 표기만 쉽게 바꿨습니다.

## 확인 결과

- 기존 단위 테스트 14개 통과.
- TypeScript 및 Next.js 운영 빌드 통과.
- 별도 테스트 데이터와 jsdom으로 신규 입력, 필수값 검사, 임시저장, 확인창 취소·제출,
  온실가스/ESG 반려 재제출, 메뉴 펼치기, 관리자 집계·필터 동작 검증.
- Chromium은 실행 환경 소켓 권한 제한으로 시작하지 못했습니다. 실제 브라우저의 시각적 검증과
  운영 계정의 인증 후 입력·서버 저장은 이번 테스트에 포함되지 않았습니다.

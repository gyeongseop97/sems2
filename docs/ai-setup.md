# SEMS2 외부 AI API 연결

API 키는 **SEMS2 서버에만** 등록합니다. 브라우저나 GitHub 코드에 키를 넣지 않습니다.
이 구현은 OpenAI 호환 `POST /chat/completions`와 Bearer 인증을 사용하는 외부 API를 지원합니다.
다른 업체 고유 API 형식은 별도 연결 코드가 필요합니다.

## 1. 업체에서 확인할 값

| 서버 설정 이름 | 넣을 값 |
|---|---|
| `SEMS_AI_BASE_URL` | API 기본 주소. 끝에 `/chat/completions`를 붙이지 않음 |
| `SEMS_AI_API_KEY` | 업체에서 발급한 API 키 |
| `SEMS_AI_MODEL` | 해당 키로 사용 가능한 정확한 모델 ID |

텍스트 모델로 입력 도움말, 보고서 설명, 고객사 답변을 사용할 수 있습니다.
증빙 읽기는 **이미지와 PDF를 API로 직접 받는 모델**이 필요합니다.
업체 서비스 화면에서 파일을 읽는 기능과 API의 파일 입력 지원은 다를 수 있습니다.

## 2. 서버에 등록

Vercel을 사용하면 프로젝트의 **Settings → Environment Variables**에 위 세 값을 등록하고 다시 배포합니다.
운영 서버는 Production, 시험 배포는 Preview에 설정합니다. 키는 Secret으로 저장합니다.
환경변수 변경은 새 배포부터 반영됩니다.

로컬에서는 `.env.example`을 `.env.local`로 복사한 뒤 세 값을 넣고 개발 서버를 다시 시작합니다.
`.env.local`은 Git 추적에서 제외되어 있습니다.

```dotenv
SEMS_AI_BASE_URL=https://업체의-API-기본주소/v1
SEMS_AI_API_KEY=발급받은-키
SEMS_AI_MODEL=업체가-안내한-모델-ID
SEMS_AI_PROTOCOL=chat
SEMS_AI_FILES_ENABLED=false
SEMS_AI_STRUCTURED_OUTPUTS=false
```

실제 주소와 키로 위 예시 값을 바꿉니다. `SEMS_AI_PROTOCOL=chat`은 외부 호환 API의 기본값입니다.
이미지와 PDF 입력을 둘 다 지원하는 것이 확인되면 `SEMS_AI_FILES_ENABLED=true`로 바꿉니다.
JSON Schema 구조화 응답을 지원하는 것이 확인된 경우에만 `SEMS_AI_STRUCTURED_OUTPUTS=true`로 바꿉니다.
구조화 응답을 꺼도 텍스트 JSON 응답을 검증해 사용할 수 있습니다.

MonoRouter를 사용하는 경우 기본 주소는 `https://monogpt.kr/api/monorouter/v1`로 설정합니다.
이 주소에서는 출력 길이 필드 `max_completion_tokens`를 자동 적용합니다.
다른 호환 API는 기본적으로 `max_tokens`를 사용하며, 필요한 경우
`SEMS_AI_CHAT_TOKEN_FIELD=max_completion_tokens`로 지정할 수 있습니다.
모델 ID와 파일 입력 지원은 사용하는 업체의 API 문서 또는 모델 목록에서 확인합니다.

## 3. 연결 확인

1. SEMS2에 정상 로그인한 뒤 **AI 답변 작성** 탭을 엽니다.
2. 확정자료가 있는 회사·연도를 선택해 실적 질문을 입력합니다.
3. 답변에 표시된 근거를 원자료와 대조합니다. 자료가 없으면 생성 호출 없이 필요한 자료를 안내합니다.
4. 이미지·PDF 지원을 켠 경우 입력 화면에서 작은 증빙을 읽고, 추출값·단위·기간을 확인합니다.
5. “원본을 확인했습니다”를 선택한 후 입력값에 반영합니다. 제출·승인은 기존 절차로 진행합니다.

설정 상태 확인은 키와 모델 값이 채워졌는지를 검사합니다. 업체 인증·모델 지원 여부는 실제 생성 요청으로 확인해야 합니다.
키가 맞는데 실패하면 모델 ID, 남은 크레딧, API 형식, 파일 입력 지원, 구조화 응답 설정을 확인합니다.
업체의 원본 오류와 키는 사용자 화면으로 전달하지 않습니다.

## 적용 기능과 처리 범위

| 기능 | 위치·처리 |
|---|---|
| 증빙 읽기 | 활동자료·지표 입력. PDF/JPG/PNG/WEBP 최대 3MB, 선택한 한 수치 추출 |
| 입력 도움말 | 지표 입력. 등록된 정의·단위·산식·증빙 기준 설명 |
| 보고서 설명 | 보고서 편집. 저장된 보고서의 회사·자료연도에 맞춰 초안 생성 |
| 고객사 답변 | 별도 AI 답변 탭. 회사·연도별 확정자료와 근거, 부족한 자료 제시 |

권한은 기존 로그인과 회사 조회 권한을 사용합니다. 실적은 확정된 자료만 집계하며,
미등록 값과 실제 0을 구분하고 목표와 실적을 구분합니다. 증빙 원문은 승인 상태와 저장소 접근 권한을 확인합니다.
기밀 표시 증빙은 자동 참조에서 제외합니다. 답변당 원문은 최대 2개, 근거는 최대 40개만 사용합니다.
AI는 등록된 데이터를 자동으로 저장·제출·승인하지 않습니다. 비율 지표의 분자·분모는 직접 입력합니다.
AI 결과는 검토용 초안이며, 올바른 근거 ID 검증이 문장·수치 전체의 정확성을 보증하지는 않습니다.

선택한 자료와 질문은 설정한 외부 API로 전송됩니다.
한 번의 답변은 최대 출력 3,000토큰, 증빙 추출은 1,800토큰이며 재시도를 자동 반복하지 않습니다.
서버 프로세스별 사용자당 분당 8회 제한이 있습니다. 전체 서버 공통 한도나 월 비용 상한은 아니므로
운영 비용 상한은 API 업체에서 별도로 설정합니다.

참고: [Vercel 환경변수 공식 안내](https://vercel.com/docs/environment-variables).

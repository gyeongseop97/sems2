SEMS2 AI 기능 적용 파일

포함 기능
1. 증빙 PDF/이미지에서 선택 항목의 입력값 추출
4. 지표 입력 기준·증빙 도움말
5. 보고서 설명 초안
3. 별도 AI 답변 작성 탭: 확정된 등록 자료를 근거로 고객사 답변 작성

이 파일은 코드 적용 패치이며 운영 사이트에 반영된 상태는 아닙니다.
기준 소스: github.com/gyeongseop97/sems2
기준 커밋: 4cf5137e3645887ec17cdff84370f284c7a7e126
구현 커밋: 790c526 (현재 작업환경의 로컬 브랜치)

개발자가 저장소 루트에서 적용하는 순서
1. 기존 수정사항을 보관하고 새 작업 브랜치를 만듭니다.
2. git apply --check /패치의/경로/SEMS2_AI_features.patch
3. 검사에 성공하면 git apply /패치의/경로/SEMS2_AI_features.patch
4. npm ci
5. npm run test:unit
6. npm run build
7. GitHub에 반영하고 기존 운영 배포 절차를 진행합니다.

다른 수정사항과 충돌하면 강제로 덮어쓰지 말고 변경 내용을 병합합니다.
실제 API 키는 GitHub 또는 이 문서에 넣지 않습니다.

API 연결
SEMS_AI_BASE_URL = 업체의 API 기본 주소 (/chat/completions 제외)
SEMS_AI_API_KEY = 발급받은 키
SEMS_AI_MODEL = 업체가 안내한 정확한 모델 ID

Vercel: 프로젝트 Settings → Environment Variables에 등록 후 다시 배포.
로컬: .env.local에 등록 후 개발 서버 재시작.
상세 설정과 지원 조건은 API_connection_guide.md를 참고하세요.

검증 결과
- 단위 테스트 149개 통과 (실제 API 호출 없이 SDK 요청 형식도 검증)
- TypeScript 및 수정 소스 ESLint 통과
- Next.js 운영 빌드 통과
- Sites 호환 빌드와 기존 렌더링 테스트 2개 통과
- 실제 API 인증·요금·모델 지원 및 로그인 후 브라우저 동작은 미확인

API 키와 모델이 없으면 화면은 연결 설정이 필요하다고 안내합니다.
선택한 질문·자료는 설정한 외부 API에 전송됩니다.
AI 값은 원본 확인 후 반영하며 기존 제출·승인 절차를 유지합니다.
보고서와 답변은 검토용 초안입니다.
